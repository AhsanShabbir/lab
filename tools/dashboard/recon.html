Workflow


1. subfinder / assetfinder / findomain → subs.txt
2. dnsx → dns.json
3. httpx → live.txt
4. gau + waybackurls → urls-archive.txt
5. katana → urls-live.txt → urls.txt
6. nuclei (live + urls-scan) → results.jsonl
7. sqlmap → sqlmap/vulnerable.txt (highlighted in dashboard)
8. optional ffuf → fuzz/
9. burp → manual testing
